# テストケース

## 適用範囲

| 対象ケース                                                | 適用される環境・到達方法                                                                                             |
| --------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 全ケース                                                  | desktop と mobile の両方。                                                                                           |
| チャンネルの Videos・Shorts・Streams ページに関するケース | カテゴリページの直接読み込み（ハードナビゲーション）と、ページを再読み込みしない移動（ソフトナビゲーション）の両方。 |
| メンバー限定に関するケース                                | 任意のチャンネルページ（Play All メニュー経由）。直接読み込みとソフトナビゲーションの両方。                          |

## ボタンとメニュー

| ケース                     | 条件                                                     | 操作                                                         | 期待結果                                                                                                                         |
| -------------------------- | -------------------------------------------------------- | ------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| 初期表示のボタンとメニュー | チャンネルの Videos ページで Latest が初期選択されている | ページを表示する                                             | 「Play All (Latest)」とラベル付けされた Play All ボタンがちょうど1つ表示される。独立した Play All メニューは閉じた状態で始まる。 |
| メニューを開く             | Play All メニューが閉じている                            | メニューのトグルを起動する                                   | メニューが開く。                                                                                                                 |
| メニューを閉じる           | Play All メニューが開いている                            | トグルをもう一度起動する、またはメニューの外側をクリックする | メニューが閉じる。                                                                                                               |
| 別のチャンネルへの移動     | 視聴者がチャンネルページにいる                           | 別のチャンネルへ移動する                                     | Play All ボタンとメニューは新しいチャンネルのリンクを表示し、前のチャンネルへのリンクは残らない。                                |
| 視聴ページ                 | 動画の視聴ページ                                         | ページを表示する                                             | Play All ボタンも Play All メニューも表示されない。                                                                              |

## 選択中の並び順

| ケース                       | 条件                                                                                                                            | 操作                           | 期待結果                                                                           |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------- | ------------------------------ | ---------------------------------------------------------------------------------- |
| 選択した並び順への追従       | Play All ボタンが表示されているカテゴリページ                                                                                   | ページ上で別の並び順を選択する | ボタンは新しく選択した並び順を表示する（Popular 選択時は「Play All (Popular)」）。 |
| ソートドロップダウンへの追従 | メンバーシップ特典のあるチャンネルのカテゴリページ。並び順操作が3つのチップの代わりに、現在の並び順をラベルに持つドロップダウンチップになっている | ドロップダウンを開いて別の並び順を選択する | ボタンは新しく選択した並び順を表示し、リンク先もそれに追従する。       |
| オーディエンスフィルタチップの無視 | 同種のページで、ソートドロップダウンの隣に「Members only」「Public」のフィルタチップが表示されている                       | フィルタチップのどれかを切り替える | ボタンは現在の並び順のラベルとリンク先を保持する。                                 |
| Oldest 解決の遅延            | Videos / Oldest の解決が遅延している間に、視聴者が Oldest、次に Latest、次に Popular を選択する                                  | Oldest の解決が完了する        | ボタンは「Play All (Popular)」のままで、選択は Popular にとどまる。                |

## リンク先の動画

下表の各ケースは、カテゴリ C ∈ {Videos, Shorts, Streams} のそれぞれに適用され、9つの組合せすべてを網羅する。

| 条件                                             | 操作                             | 期待結果                                                                                                                                                                                                                          |
| ------------------------------------------------ | -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| チャンネルの C ページで Latest が選択されている  | 「Play All (Latest)」を起動する  | リンク先のプレイリストパネルの再生可能な最初の3本が、チャンネルの C / Latest ページの最初の3本と同じ順序で一致する。YouTube 自身が再生不可として示す行（非公開動画など）はこの比較から除外するが、その表示のない行は除外しない。  |
| チャンネルの C ページで Popular が選択されている | 「Play All (Popular)」を起動する | リンク先のプレイリストパネルの再生可能な最初の3本が、チャンネルの C / Popular ページの最初の3本と同じ順序で一致する。YouTube 自身が再生不可として示す行（非公開動画など）はこの比較から除外するが、その表示のない行は除外しない。 |
| チャンネルの C ページで Oldest が選択されている  | 「Play All (Oldest)」を起動する  | リンク先のプレイリストパネルで選択される動画が、チャンネルの C / Oldest ページの最初の動画と一致する。                                                                                                                            |

## Oldest プレイリスト

| ケース                             | 条件                               | 操作                            | 期待結果                                                                                                                                                                                                                   |
| ---------------------------------- | ---------------------------------- | ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 全カテゴリ共通の古い順プレイリスト | カテゴリで Oldest が選択されている | 「Play All (Oldest)」を起動する | リンク先は、全カテゴリのアップロードを古い順に含む単一のプレイリストである。そのカテゴリの最古の動画が選択される。別のカテゴリにさらに古いアップロードがある場合、選択された動画はプレイリストパネルの先頭項目にならない。 |

## メンバー限定のリンク先

Play All メニューは、メンバーシップ特典のあるチャンネルではメンバー限定のエントリも表示する。メンバー限定プレイリストは動画（UUMF）とライブ配信（UUMV）にのみ存在し、Popular の並び順と古い順専用プレイリストはなく、メンバーシップのないチャンネルでは表示されない。

| ケース                          | 条件                                 | 操作                                    | 期待結果                                                                                                                                                                            |
| ------------------------------- | ------------------------------------ | --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| メンバーシップがあるときのエントリ | メンバーシップ特典のあるチャンネル | Play All メニューを開く                  | メニューにはメンバー限定の動画とライブ配信のエントリが `Videos (Members Latest)` のように名付けられて並び、それぞれ Latest と Oldest を持つ。Latest のリンク先はそのチャンネルの UUMF / UUMV プレイリストで、Oldest のリンクはプレイリストの最古の項目から再生を開始する。 |
| メンバーシップがないときのエントリ | メンバーシップ特典のないチャンネル | Play All メニューを開く                  | メンバー限定のエントリは表示されない。                                                                                                                                                |
| Latest のリンク先               | メニューにメンバー限定エントリがある | メンバー限定の Latest エントリを起動する | リンク先はそのチャンネルのメンバー限定プレイリストで、プレイリストパネルの行はメンバー限定プレイリストページと同じ video id を同じ順序で並べる。行は再生可否で絞り込まない: 未ログイン視聴者にはメンバー限定の行はすべて再生不可だが、比較は成立する。 |
| Oldest のリンク先               | メニューにメンバー限定エントリがある | メンバー限定の Oldest エントリを起動する | プレイリストパネルで選択される行は、メンバー限定プレイリストの最古の項目、すなわちメンバー限定プレイリストページの最後の行である。                                                    |

## 失敗

| ケース                   | 条件                                          | 操作                             | 期待結果                                                                                                                 |
| ------------------------ | --------------------------------------------- | -------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Oldest の解決失敗        | Videos / Oldest 単体が解決できない            | Oldest を選択する                | ボタンは、機能するプレイリストリンクの代わりに「Play All (Oldest) (error)」と表示する。                                  |
| error ボタンは遷移しない | 「Play All (Oldest) (error)」が表示されている | ボタンを起動する                 | 視聴者は同じページにとどまる。                                                                                           |
| 他の並び順は利用可能     | Videos / Oldest 単体が解決できない            | メニューから別の並び順を選択する | 他の利用可能なメニューの選択肢は引き続き利用でき、Popular を選択すると機能する「Play All (Popular)」ボタンが表示される。 |

## レビュー

E2Eテストは、網羅性を確認するテストとレビューのためのテストに分かれる。レビューテストは `tests/review/review.test.ts` に置き、網羅性のテストは `tests/e2e/` に置く。録画とレビュー材料は、独立した撮影パイプラインではなくPlaywright内蔵のtraceとHTML reportで行う。

レビューの単位は操作文を名前にする `test.step()` ステップで、1ステップを意図1つと確認1組に対応させ、アサーションは通常の `expect()` で書く。主要なlocatorには `.describe("name")` で名前を付ける。レビューの操作は人間らしくする。文字入力は `pressSequentially(text, { delay: 120 })`、クリックは `click({ steps: 15 })` を使う。

| テスト名 | 操作シナリオ |
| --- | --- |
| `Review` | 各カテゴリ・並び順のPlay Allボタンと、その再生先プレイリストを確認し、メンバーシップ対応チャンネルのドロップダウンにメンバー限定エントリが並ぶことを確認する。 |

シナリオは、選択した各E2Eプロジェクトのブラウザ・デバイスで1回ずつ実行する。モバイルは通常プロジェクトのPixel 5縦向きviewportを維持する。

各セルはクリック順に2枚のviewportスクリーンショットをテスト結果に添付する。チャンネルページ上のPlay Allボタン、次にプレイリストの再生先である。HTML reportはテストattachmentをその添付順に並べる。

### レビューの実行と閲覧

`bun run test` は網羅性とレビューの両方のテストを実行する。`bun run test:review` は `tests/review/` のテストだけをワーカー1でChrome desktopとChrome mobileに実行する部分実行である。どちらの実行でも、レビューのtraceは成功試行を含めて常に保持する。レビュー以外のテストは失敗試行のtraceだけを保持する (`trace: "retain-on-failure"`)。

両方の実行結果は同じPlaywright HTML reportに保存され、直近の実行結果で上書きされる。どちらの実行後も再テストせずに閲覧でき、閲覧のための `bun run test:review` は任意である。

Play Allボタンの通常・hover・focus時の背景色は、通常のインライン指定より拡張CSSの色を優先する。traceスナップショット内でもこれらの色を維持し、ビューアの対象要素用の枠線を抑制する。他の対象要素のハイライトとクリック位置のマーカーは維持する。

`bun run review` は最初にreportパッチ (`scripts/patch-report.ts`) を適用してから`--port 0` でreportサーバーを起動する。パッチは、trace viewerのAttachmentsタブを、buttonとdestinationのペアをカテゴリと並び順の見出し（例: `Videos - Latest`）の下に縦に積む2列のグリッドにし、Attachmentsタブを初期選択にする。パッチは冪等で、再サーブしても見た目は変わらず、レポートがまだ無い場合は明示的に失敗する。パッチはsnapshotペインを小さな固定高さにし、Attachmentsペインが最初から最大の高さになるようにする。ペイン高さは初期化しない。最大近くのseedはsnapshotペインをほぼ潰し続け、ブラウザズームのたびにペイン境界が動くためである。パッチはtrace viewerのfilm stripの高さも固定し、動画サムネイルの非同期生成でtimelineが伸びてtraceを開いた後にペイン境界が動くことを防ぐ。起動時に表示されたURLを開き、report内でテスト名からレビューテストを選ぶ。テストを開くとステップとtraceが表示され、traceビューアで操作の再生と各ステップ時点のページ状態を確認できる。Ctrl+Cでサーバーを停止する。所有者はtraceとreportで観測された振る舞いを判断する。アサーションの合否は録画の見た目ではなく、ランナーのpass/failに従う。
